# TTC Ramsharde – Vereinswebsite

Eine moderne, performante und responsive Website für den Tischtennisverein TTC Ramsharde. 
---

## 🛠 Tech Stack

* **Frontend:** HTML5, SCSS (Sass), JavaScript (ES6+), Bootstrap 5
* **Build Tools & Workflow:** Gulp, BrowserSync, Autoprefixer, CleanCSS
* **Performance & UX:** Fluid Typography (`clamp()`), Owl Carousel, CSS Grid / Flexbox
* **Icons & Typografie:** Local Webfonts (`Geist`), SVG Icons

---

## 🚀 Key Features & Highlights
* **Artikel- Management:** Dynamische Erstellung, Verwaltung und Darstellung von Vereins-News, Spielberichten und Ankündigungen sowie Social Media Verlinkungen.
* **Spieler- & Kader-Verwaltung:** Strukturierte Erfassung von Spielerprofilen, TTR-Punkten und Mannschaftsaufstellungen.
* **Galerie- & Medien-Management:** Flexible Verwaltung von Bild-Uploads, Fotoalben und Event-Impressionen.
* **Modulares SCSS-Setup:** Strukturierte Partial-Architektur (`_base`, `_pages`, `_components`) mit elegantem Body-ID-Scoping (`body#page`) für saubere Wartbarkeit.
* **Interaktives Galerie-Modal:** Inklusive Tastatur-Navigation, Swipe-Unterstützung und optimiertem Bild-Handling.
* **Mannschafts- & Matchcenter-Module:** Spezifisch angepasste Overlays und Layouts für Bilanzen, TTR-Punkte und Paarkreuze.
* **Fluid Responsiveness:** Stufenlose Anpassung von Texten und Abständen über alle Viewports hinweg ohne unnötigen CSS-Ballast.
